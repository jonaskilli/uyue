## 1. 结论速览（针对当前项目）

当前项目已有 `/workspace/scene-effects/`：`语义 cue → 稳定效果 ID → 预设 tracks → Android Canvas 自定义 View（WeatherOverlay.kt）` 的三层架构，另有 74 个视觉预设、50 条语义效果、17 种 track kind。**绘制层不用推倒重来，只要补「爆炸/火焰/斩击」的效果资源和播放器**。

推荐优先级：

| 优先级 | 方案 | 为什么 |
|---|---|---|
| ★★★★★ | `patch-gg/pixelfx` 导出序列帧 + 现有 `WeatherOverlay` 扩一个 `FxOverlay` | 244 个特效里 fire 12 / explosions 12 / melee 12（斩击）/ impacts 11 / moves 12（整套出招到受击），MIT 可商用，纯代码无图片，能一键导出透明 PNG 精灵图 + Aseprite JSON；Android 只要播序列帧 |
| ★★★★★ | `SolidKeyAB/kmpmedia`（OGSlash）+ `pixelfx` 的 melee | 斩击缎带、分叉闪电、速度线、余烬，纯 Compose/Kotlin 无 shader，配置文件可序列化，最贴合「比武/斩杀」 |
| ★★★★☆ | `effekseer/Effekseer` + `effekseer/EffectMaterials` | 专业级爆炸/打击特效编辑器，官方支持 Android/iOS（OpenGL ES 运行时），素材 CC0，可导出 2D 动画；但要接 NDK/C++ 运行时，成本最高 |
| ★★★★☆ | `bytedance/AlphaPlayer` / `Tencent/vap`（旧版 MIT） | 透明视频特效播放，画面最华丽（真粒子/光效/烟雾），移动端硬解；缺点是要先做素材 |
| ★★★★☆ | `airbnb/lottie-android` / `Tencent/libpag` + 免费动效素材 | 生态最成熟，LottieFiles 有大量免费火焰/爆炸 JSON；纯 Kotlin 接入，改色换字方便 |
| ★★★☆☆ | Android 原生轻量库（Leonids / Konfetti / Particles-Android / ExplosionField / ParticleSmasher…） | 直接一个 View 叠在屏幕上，几百 KB，无需引擎，适合「火花/爆散/碎裂」类瞬时反馈 |
| ★★★☆☆ | Web/JS 库（tsParticles / canvas-confetti / fireworks-js / PixiJS） | 放 WebView 里跑最省事，或把代码当参考移植到 Canvas；注意 WebView 内存和低端机帧率 |
| ★★★☆☆ | `APNG4Android` / `Fresco` 播 APNG、GIF、动 WebP | 最土但最稳：把特效做成动图直接盖在文字上 |

## 13. 落地到当前 Legado 项目的建议路线

现有架构（`/workspace/scene-effects/README.md` 第 3~6 节）：`朗读段落 → 语义 cue → 稳定 ID → tracks → WeatherOverlay 绘制`。

**MVP（改动最小，半天~一天）**
1. 从 `pixelfx` 导出需要的序列帧：
   ```bash
   node tools/render.mjs explosions/big-explosion --sheet
   node tools/render.mjs fire/campfire --sheet
   node tools/render.mjs melee/double-slash --sheet
   node tools/sheets.mjs            # 或一次性导出全部
   ```
   把生成的透明 PNG + JSON 放进 `app/src/main/assets/fx/`。
2. 参考 `scene-effects/android/WeatherOverlay.kt` 新增 `FxOverlay.kt`：一个透明 `View`，`play(fxId, x, y)` 按 JSON 里的 frame rect / duration 用 `Canvas.drawBitmap` 播帧，`postInvalidateOnAnimation()` 驱动，播完自动隐藏；支持 `hold` 与同时叠 2 层。
3. 在 `scene-effects/presets/semantic-effects.json` 增 `fx_explosion` / `fx_fire` / `fx_slash` 等稳定 ID，在 `mapping/semantic-cues.json` 增 `爆炸 → fx_explosion`、`燃烧 → fx_fire`、`斩/劈/一刀 → fx_slash` 的映射；`SceneEffectResolver` 输出一个新 track kind（如 `fx`，带 `id / at / duration / x / y`）。
4. 朗读推进到该句时 `fxOverlay.setTracks(tracks)`，与已有雨雪层互不干扰。
5. 加「减少动态效果」开关；`pixelfx` 的 `act.hits` 里有 `stop/shake/amp` 命中停顿参数，可直接喂给现有的 `shake` track，打击感立刻上一个档次。

**进阶**
- 想要设计感更强的火焰/爆炸：`Lottie`（`lottie-android` + LottieFiles 免费 JSON）或 `libpag`；包体敏感就用 `pixelfx` 序列帧。
- 想要电影级光效：`AlphaPlayer` / 旧版 `VAP` 播透明 MP4，但需先做素材（可用 Effekseer 导出 PNG 序列再合成）。
- 想让 AI 现场生成特效：`pixelfx` 自带 `skills/pixelfx`（`new → render → check` 闭环），可以让模型按小说情节生成新特效文件，再导出序列帧。
- 想完全不引入资源：`Leonids` / `Particles-Android` 的粒子发射器 + `Kenney CC0` 贴图，在 `WeatherOverlay` 里加 `variant = fire / embers / sparks / slash` 分支即可。

## 17. 注意事项

1. **许可证**：`pixelfx` 的 MIT 不覆盖 `gallery/fonts` 字体；Shadertoy 默认 **CC BY-NC-SA 3.0**（不可直接商用）；LottieFiles / itch.io / OpenGameArt 每个作品许可可能不同；Effekseer 工具 MIT、示例特效多为 CC-0、EffectMaterials 全部 CC0 —— 三者不是一回事。
2. **性能**：朗读场景是长时间前台，特效要「短促、可中断、页面不可见即暂停」；优先播 8~20 帧序列帧或 200~500 粒子的 Canvas 层，别在 WebView 里常驻一个 WebGL 循环。
3. **无障碍**：沿用 `Aether` 与本项目 README 的做法，系统「移除动画」/省电模式时关闭 flash、震屏、强闪。
4. **包体**：序列帧建议 WebP/透明 WebP 或 320×180 像素风小图；`libpag` 约 +3~4MB；`Effekseer` 运行时带 .so；`pixelfx` 只导需要的几十个特效即可。
