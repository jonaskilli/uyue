# TTS 插件说明

TTS 插件用于管理在线朗读的**插件**与**音色配置**，让阅读可以用外部接口把文字合成为语音。本页分为三个标签页：

* **配置列表**：一条条具体的音色配置（音色标签、所属插件、请求地址与参数、音量/语速/音调等）。
* **插件日志**：插件合成、请求、后处理过程的日志，排错时先来这里看。
* **插件**：可被配置引用的插件，封装了请求方式、URL/请求头/请求体模板、返回音频路径以及默认变量等。

## 基本概念

* **插件**：提供「怎么请求、音频在哪」的通用能力，可写 JS 代码、设置默认变量与用户变量。
* **配置**：绑定到某个插件的具体音色，设置音色标签（voiceTag）、语言、试听文本、请求参数与音频后处理参数。朗读时按音色标签选择对应配置。
* **分组**：把配置按分组/子分组归类，便于管理，也支持分组级的音频后处理。

## 常用操作

* 点右上角「**新增**」：在「配置列表」页新建音色配置，在「插件」页新建插件。
* 「**新建分组**」：只在「配置列表」页显示，用于给配置分组归类。
* 「**初始化内置配置**」：写入内置的一批配置，适合首次使用或误删后恢复。
* 「**导入/导出**」：菜单里四个入口的目标是固定的，与当前所在标签无关——
  * 导入(配置列表) / 导出(配置列表)：操作音色配置；
  * 导入(插件) / 导出(插件)：操作插件。
* 「**全部禁用**」：一次性禁用所有配置，批量停用时用。
* 「**查看所有标签**」：列出当前所有可用（已启用）配置的音色标签。

## 音频与播放设置

* 「**全局音频调节**」：合成后生效的全局后处理（语速/音量/音调），`1.0` 表示不调整，范围 `0.1~3.0`。
* 「**快节奏播放**」：开启后去除静音片段，让朗读节奏更紧凑。
* 「**检测尾音**」：检测合成音频结尾是否合格（戛然而止等），不合格可自动重新合成。可设置最多重合成次数、尾音判定阈值、最短检测时长等；次数设为 `0` 时只记录不回退合成。

## 常见问题

### 1. 点某个配置没有声音 / 合成失败？
切到「**插件日志**」标签查看报错，常见原因是插件的请求地址、请求头或返回音频路径填写有误，或密钥/变量未配置。

### 2. 为什么导入后看不到配置？
注意导入入口的目标：「导入(配置列表)」和「导入(插件)」分别对应不同数据，选错入口会导致看不到预期内容。

### 3. 音量、语速改了没效果？
配置级、插件级、分组级和全局后处理会叠加生效。任一级别设为 `1.0` 表示不调整，可逐级检查。
